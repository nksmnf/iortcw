# Файлы для игры на серверах

Больше половины населённых серверов RTCW играют на нестандартных картах и под
модами. Без их файлов на сервер либо не пускает, либо приходится ждать долгую
докачку по UDP прямо при входе.

Этот набор — то, что реально крутится в сети сейчас, собранное заранее.

---

## Где лежит

На Маке: `~/.claude/jobs/<id>/tmp/serverpaks/` — 18 файлов, 112 МБ.

На планшете уже скопировано в **Файлы → На iPad → iORTCW → main**, рядом с
`pak0.pk3` и остальными. Ничего дополнительно делать не нужно.

## Что внутри

**Моды** — без них не пустит на сервер под Omni-Bot, а это самая населённая
часть сети:

| Файл | Что это |
|---|---|
| `mmod.pk3` | серверный мод |
| `omnibot_rtcw.pk3` | игровые модули мода |
| `ob_media.pk3` | его ресурсы |

**Карты** — 15 штук, те, что встречались на живых серверах:

`back_to_carnage`, `denoflions_dual`, `hydro_dam_v2`, `mp_base3`, `mp_castle2`,
`mp_marketgarden`, `mp_omaha_2`, `mp_q3dm17`, `mp_tank`, `mp_theguns`,
`mp_xdam`, `te_escape2`, `te_frostbite`, `te_industrial`, `te_ufo`.

Источник — открытое зеркало `rtcw.life/files/toak/`, то самое, с которого
сервер раздаёт файлы игрокам штатной докачкой (`sv_dlURL`).

---

## Почему это не один пак

Просьба «упаковать одним паком» понятна, но так сделать нельзя, и причина
жёсткая.

Сервер с `sv_pure 1` — а это почти все — не просто требует «нужные файлы». Он
называет каждый пак поимённо и сверяет его контрольную сумму с той, что
прислал клиент. Склеенный архив — это другой файл с другой суммой и другим
именем: он не совпадёт **ни с одним** паком сервера, и вход закончится тем же
`Unpure client detected`, ради избавления от которого всё и затевалось.

Поэтому паки лежат отдельными файлами и должны такими остаться. Для переноса
их можно положить в zip, но на планшете они обязаны быть распакованы по
отдельности в `main/`.

---

## Чего этот набор не покрывает

Карты и моды с серверов, у которых своё зеркало: `rtcwPub`, `FFmod`,
`s4ndmod`. Там встречаются `church`, `forest`, `trainyard`, `mp_winter`,
`mp_tram`, `mk_flooded_town` и другие.

Для них работает штатная докачка: сервер отдаёт недостающий файл при входе.
В этой сборке она идёт по UDP — медленнее HTTP, потому что curl в сборку для
iOS не входит, — но работает и ничего настраивать не нужно, `cl_allowDownload`
включён по умолчанию.

---

## Если сервер всё равно не пускает

1. Посмотрите лог: **Файлы → На iPad → iORTCW → main → `rtcwconsole.log`**.
   Подробный лог включён по умолчанию (вкладка «Мультиплеер» → «Диагностика»).
2. `Unpure client detected` — не хватает пака именно этого сервера. Его имя
   будет в строках `Need paks:` выше.
3. `Incorrect checksum for file` — скачанный файл побился, удалите его из
   `main/` и зайдите снова.
4. Если сервер держит мод, которого нет ни здесь, ни у него на зеркале, войти
   не получится: файлы в этом случае взять неоткуда.
